## Como criar um novo plano

1. Copie o formato de `plan-001` mantendo seções: Contexto, Agente/skills, Passo a passo, Validação, Critérios de aceite, Entrega, Próximos passos.
2. Defina o agente via `agents/README.md` e as skills via `skills/README.md`.
3. Atualize a tabela acima.
